# TimeSeries lifecycle

Import `TimeSeries` from `@gemologic/sheen-charts/time-series` when an application needs the uPlot renderer. The package root also exports it, but the dedicated entry makes the heavy engine boundary explicit. `@gemologic/sheen-charts/core`, `/svg`, and `/table` remain renderer-free; installed-consumer builds fail if those entries retain uPlot or d3.

The server emits the complete figure caption, required narrative summary, a sized SVG fallback, empty content when applicable, and the bounded native-table disclosure. The plot region reserves the exact requested height before JavaScript. Hydration retains the figure, plot region, fallback, disclosure, table, and rows; uPlot is appended inside the existing plot region and the fallback is hidden only after the first canvas is ready. Do not key a chart by theme, width, loading state, or accepted-data revision.

TimeSeries validates the same immutable columnar boundary as `toColumnar`. UTC epoch milliseconds remain milliseconds through uPlot's `ms: 1` option. Finite typed columns pass to the renderer without copying. A series containing `NaN` is converted to uPlot's explicit `null` gap form, so the line breaks rather than drawing zero or interpolation. The server fallback caps path commands while preserving encountered gaps, preventing a 100,000-point response from emitting a 100,000-command SVG.

Scoped theme probes resolve chart, market, accent, grid, axis, crosshair, type, and line-width tokens from the actual `ThemeScope`. Token changes mutate no Solid chart content and do not replace the canvas. They update renderer drawing configuration and schedule one canvas redraw. A `ResizeObserver` coalesces responsive size changes onto animation frames. Accepted data changes call `setData` on the same uPlot instance; `loading` marks the retained figure and table busy without replacing either. Disposal cancels pending resize work, disconnects the observer, destroys uPlot, and releases the shared scoped token probe.

`__unsafe_uplot` is a typed, lint-warned escape hatch for bands, draw order, focus, padding, plugins, pixel alignment, and selection styling. Sheen owns width, height, aligned data, millisecond semantics, series, axes, scales, legend, cursor, hooks, IDs/classes, and timezone formatting because those fields enforce lifecycle, accessibility, theming, and cleanup. Applications that need to replace an owned field need a chart-contract change rather than an option collision.

The visual axis uses explicit provider locale and the requested formatting-only timezone. Tick labels choose a compact date/time shape from uPlot's accepted scale increment, while the native data table keeps the intentionally complete date and time representation. The chart draws horizontal grid lines only, without axis spines or a chart background. Each series resolves the same solid, dashed, dotted, or dash-dot non-color encoding in the server fallback, enhanced canvas, retained tooltip, and legend.

Pointer inspection updates one retained DOM tooltip from uPlot cursor hooks without publishing Solid state. Charts sharing `cursor.sync` mirror the nearest index and keep their own localized values. The plot is one keyboard tab stop: Left and Right move one visible sample, Home and End move to the visible range boundaries, and Escape clears inspection. Its polite status announces the same domain and visible-series values. Legend buttons expose pressed state and keep hidden series in the native table. Dragging selects an X range, double-click and the Reset zoom button restore the full range, and Zoom in/out provide the keyboard-equivalent operation. Accepted data refreshes preserve an active zoom when its range remains meaningful, as well as the canvas, tooltip, annotation, focus, and table owners.

Current local qualification includes deterministic dark SSR, delayed hydration with exact root and geometry retention, real accepted and failed refreshes sampled for twenty frames, scoped theme redraw without canvas replacement, responsive resize, destroy/remount cleanup, synchronized pointer inspection, keyboard inspection, legend toggles, drag and toolbar zoom, zoom preservation across refresh, an open-table axe pass, and a reviewed dark Chromium baseline. Live Chrome DevTools reports Lighthouse accessibility 100, no component warnings or errors, 69ms local LCP, and zero layout shift. These are local Chromium results, not WebKit, physical Safari, Firefox, hosted CI, or manual assistive-technology proof.
