# Unsaved changes implementation boundary

`useUnsavedChanges(() => boolean)` is exported from `@gemologic/sheen-patterns`. Call it under AppShell in a Solid owner. Registrations have independent identities, aggregate app-owned dirty predicates, and unregister on owner disposal. AppShell installs a native beforeunload listener while its registry is dirty and removes it when clean or disposed. No data is saved or discarded by this mechanism.

Four registry/AppShell unit and SSR cases, the patterns build, lint/typechecks, and metadata validation pass. The initial reload failure was a test racing initial hydration: CDP identified its sole listener as Vite's willUnload handler, not the shell guard. Tests now observe the app's dirty state before initiating reload. Three native full-Chromium scenarios pass three consecutive runs each: cancellation retains the draft, saving removes the guard, another dirty editor remains protected, and disposing the dirty owner permits reload. A separate delayed-JavaScript test verifies a pre-hydration draft retains its server DOM/value and becomes registered as dirty after replay. Protection cannot run before client code is available; these results are not a guarantee against browser termination or pre-hydration document loss.

AppShell now accepts an optional router adapter and mounts a localized discard confirmation inside the shell's theme context. The first pending attempt owns the destination; subsequent attempts are prevented without replacing it. Cancellation retains the current route, disposal aborts the prompt, and an externally accepted location change invalidates the old attempt. Confirmation/retry failure opens a generic navigation-failure dialog without exposing transport details. Loupe supplies an app-owned adapter using its existing Solid router dependency. Three browser cases pass three consecutive runs each: link cancellation/confirmation with retained draft and restored focus, preservation of an unrelated app blocker, and browser-forward cancellation/confirmation. History retries require a destination-matched one-use bypass that survives until the asynchronous popstate; a synchronous-only bypass failed the forward regression. Disposal and unrelated next attempts invalidate the permission.

The exported RouterAdapter contract exposes location, navigate, and block. A block subscription returns its disposer. Each NavigationAttempt has a synchronous preventDefault and a retry for the exact original navigation. Retry must bypass only that subscription once, preserve the original options, and become invalid after disposal; it must not force past unrelated application blockers. The guard's four pure unit cases cover clean/already-prevented navigation, first-attempt ownership, late resolution after disposal, and rejected confirmation with subsequent retry availability.

The dedicated packaged Solid adapter and title synchronization await dependency approval. Per-pane and responsive document restoration are implemented and qualified separately. Browser unload dialogs remain subject to user-agent policy and are not a substitute for app-owned draft persistence. See the [HTML BeforeUnloadEvent contract](https://html.spec.whatwg.org/multipage/nav-history-apis.html#the-beforeunloadevent-interface).
