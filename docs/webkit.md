# WebKit qualification

Run `pnpm test:webkit` after `pnpm build`. The dedicated configuration inherits the normal server and trace settings but selects only the WebKit project. Its current 254 cases cover the release-critical interaction contracts for AdminApp and every supported chrome placement, Composer, DataTable search/filter/sort/edit/export/selection/views/URL state, numbered and continuous mobile presentation, date and time controls, overlays, toasts, shell layout and scroll restoration, theme hydration, reduced motion, RTL, and retained background refresh. A previously accepted local run passed 216 cases in 4.2 minutes with two fixed workers. Two cases are intentionally skipped: a Chromium-owned raster baseline and page-inactivity timing, because Playwright exposes deterministic page-focus emulation only through Chromium CDP. WebKit visual baselines and physical Safari remain separate release evidence.

The history/cancellation follow-up passed 27 focused cases twice (54 executions) on native Linux WebKit. These cover rapid navigation beyond 50 visits, duplicate URL offsets, copied state, adapter ownership/disposal, dirty traversal, hydration, scoped drawer scrolling/persistence, detached panes, and complete/truncated Nitro upload cancellation. This is focused regression evidence, not a run of all 254 selected cases or physical Safari qualification.

The separate Ubuntu 24.04 CI job installs the locked workspace, builds it, runs `pnpm exec playwright install --with-deps webkit`, and executes this suite. Failure traces are uploaded from `test-results/webkit`. This follows Playwright's [browser dependency installation](https://playwright.dev/docs/browsers) and [CI setup](https://playwright.dev/docs/ci). There is no continue-on-error exemption. Adding the job is not evidence that hosted CI has run or passed.

The pinned Nix shell supplies the GTK, WPE, GStreamer, ICU, AVIF, codec, and font libraries required by Playwright's bundled WebKit. `SHEEN_NIX_WEBKIT=1` selects its real MiniBrowser executable with the combined private and Nix library paths; running outside that shell fails before application code when those libraries are unavailable. Do not bypass dependency checks or alias incompatible shared-library versions.

The accepted local run is native Linux WebKit behavior, not merely test discovery. The hosted Ubuntu CI job and physical Safari/macOS VoiceOver qualification remain unverified.
